The real-table export/query tests require the PROPOSAL export-enabled build
and their configured cache fixtures. A basic contract-test target does not
establish that these real-table checks were built or run. See
`the table-test build configuration <https://github.com/BossL668/CORSIKA8-kokkos/blob/d5297c43c041a22b43c65c322d9b51bc7ec8e397/tests/kokkos/em/tables/CMakeLists.txt>`_.

Many checks compare with a retained production implementation. They protect
implementation compatibility; a new physical model additionally needs an
independent physics validation.
